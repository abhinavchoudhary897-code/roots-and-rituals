Existing exhibition drafts and presentation were preserved. New frames have editable layers, local color and spacing variables, reusable primary button and exhibit card components. The original abstract landscape is an editorial vector, not an authentic artisan artwork. No external artwork permissions implied.

## Tokens
Ivory #F7F3EB, sand #E8D9C5, terracotta #A34D34, earth #594132, forest #435A44, white #FFFFFF, ink #312B26. Lora for display headings, Inter for interface and body. Georgia was unavailable in Figma; Lora was chosen to retain the editorial serif style. Base spacing 16px, radius 12px, primary button height 52px.

## Validation and limits
Desktop and mobile frame renders inspected. The initial primary button height of 100px was corrected to 52px; desktop render rechecked. Text layer families verified as Lora and Inter. This is a visual design review, not functional or accessibility testing. Tablet layout, detailed feature screens, prototype navigation, final media clearance, user testing and implementation handoff remain open. No live deployment or student testing claimed. AI assisted with editable design creation; students should review and contribute to the design and implementation.
